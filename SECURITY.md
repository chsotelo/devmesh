# Security Policy

## Reporting a vulnerability

Do not open a public issue for security problems.

Report privately through the "Report a vulnerability" button in the Security tab of this repository (GitHub Security Advisories).

We aim to send a first response within 7 days. Include the affected version,
steps to reproduce, and the impact you expect.

## Supported versions

Only the latest minor release receives security fixes.
